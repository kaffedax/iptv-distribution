LG TV

LG-installation kräver Developer Mode och en dator på samma nätverk som TV:n.

Hämta LG TV-paket (IPK)

Installationspaket 5.2.1 · släppt 1 november 2026

Så gör du

  1. 1Skapa ett LG Developer-konto. På TV:n installerar du appen Developer Mode från LG Content Store och loggar in.
  2. 2Slå på Dev Mode Status. TV:n startar om. När den är igång öppnar du Developer Mode igen och slår på Key Server.
  3. 3På en dator på samma nätverk installerar du Visual Studio Code och LG:s webOS Studio. Följ LG:s installationsguide.
  4. 4I webOS Studio väljer du Add Device i vyn Known Device. Ange ett namn själv, TV:ns IP-adress (visas i Developer Mode), port 9922 och användare prisoner.
  5. 5I webOS Studios kommandopalett väljer du webOS TV: Set Up SSH Key och TV:n. Skriv lösenfrasen som visas på TV:n när programmet frågar. Ange den bara lokalt.
  6. 6Hämta IPK-filen till datorn. Välj webOS TV: Install Application och därefter IPK-filen och TV:n.
  7. 7Välj webOS TV: Launch Application och starta Aspelin. Första gången anger du leverantörens adress, användarnamn och lösenord.

Att känna till

Appen installeras från datorn via Developer Mode. En ny installation ersätter normalt den tidigare appversionen. Developer Mode är tidsbegränsat; när tiden går ut avinstalleras appar som installerats på det sättet, så IPK-filen behöver installeras igen.

En ny IPK kan behövas för att uppdatera själva TV-appen. Vanliga uppdateringar hämtas i appen.

Kommandorad som alternativ

Installera Node.js och kör npm install -g @webos-tools/cli. Registrera TV:n med ares-setup-device och hämta nyckeln med ares-novacom --device <namn> --getkey. Installera IPK-filen med ares-install --device <namn> filnamn.ipk och starta appen med ares-launch --device <namn> com.rikard.iptv.
